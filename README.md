# graphaiportal.com

Static site for Graph AI LLC (home page + product pages). No build step: the files are served as-is.

- `index.html`: Graph AI LLC home, with MarketRank featured
- `marketrank.html`: what MarketRank is, the interface, honest results, the paper
- `xgraph.html`, `xvector.html`: product pages condensed from each repo's README, linking to GitHub for the full docs
- `assets/`: CSS, icons, screenshots, `marketrank-paper.pdf`
- `CNAME`: the custom domain for GitHub Pages (graphaiportal.com)
